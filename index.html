About this project

Digital Monitoring of Deforestation in the Amazon: a case study of Rondônia, Brazil.

The problem

Deforestation is the permanent clearing of forest for farms, roads, mining and settlements. Forests store carbon, shape rainfall and shelter wildlife, so losing them affects climate and biodiversity. Walking through a forest as large as the Amazon to check it is slow and expensive, but a satellite photographs the whole area again and again. That is what "digital monitoring" means here.

Why Rondônia

Rondônia is a state in north-western Brazil, inside the Amazon rainforest region. It lies on the southern edge of the Amazon, sometimes called the "Arc of Deforestation". Roads cut into the forest and farms spread out from them in a fishbone pattern, which is easy to spot in satellite images.

What we did

  1. Downloaded two Sentinel-2 satellite images of the same place in Rondônia, one early year and one recent year, from the Sentinel Hub EO Browser.
  2. Built this dashboard using HTML, CSS and JavaScript.
  3. Made the computer compare the two images pixel by pixel to find where forest disappeared.
  4. Turned that loss into numbers people can relate to: trees, carbon, CO₂ and personal offsets.

Impact calculatorTrees lost = hectares × trees per hectare. Carbon = hectares × carbon per hectare. CO₂ = carbon × 3.67.
Image analyzerThe core of the project. It marks forest that existed in the first image and is gone in the second, and gives the percentage lost.
Offset calculatorAdds up CO₂ from travel, flights and electricity, then divides by what one tree absorbs in a year.

How the analyzer decides what is forest

A satellite picture is a grid of tiny squares called pixels. Each pixel has a red, green and blue value from 0 to 255. Healthy forest is greener than it is red or blue, so for every pixel the code calculates 2 × green − red − blue. If the result is above a chosen threshold, the pixel counts as forest. A pixel that is forest in the first image but not in the second is marked orange as lost forest. Hectares lost = (lost pixels ÷ all pixels) × area of the image.

Limitations

  • Clouds, shadows and water can be mistaken for cleared land. The threshold slider helps, but it is not perfect.
  • This uses ordinary colour images. Professional systems also use infrared light (for example NDVI) and are more accurate.
  • Trees per hectare, carbon per hectare and emission factors are average estimates. Real values vary with the forest and the year.
  • Only two dates are compared, so this shows the total change, not what happened in between.

Data and tools

  • Satellite images: Copernicus Sentinel-2, viewed through Sentinel Hub EO Browser.
  • Conversion factors: published sources, listed in the data.js file and in the report bibliography.
  • Built with HTML, CSS and JavaScript, with AI assistance used for guidance on the code.

What this shows

Satellite images let anyone measure forest loss quickly, cheaply and repeatedly. Turning the loss into hectares, trees and CO₂ makes the problem easier to understand, and the offset calculator shows what the same emissions would mean in trees.
